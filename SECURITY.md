# Security

## Report a vulnerability

Please do **not** open a public issue for a security problem.

Use [GitHub private vulnerability reporting](https://github.com/cfmurph/teleprompter/security/advisories/new) on this repository, or email the maintainer at the address on the GitHub profile.

## Scope

This app is client-only. Still report anything that could leak local data, abuse the WebRTC signaling path, or run unexpected code in another user's browser.
